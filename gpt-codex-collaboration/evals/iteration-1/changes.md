# 从错误版本到通用协作协议

## 原因

用户要沉淀的是 Codex 与 ChatGPT 的协作方式，而不是本次网站视觉任务。旧 Skill 把业务
实例误当成协议主体，属于过拟合。

## 变化

- 新建 `gpt-codex-collaboration`，只负责多模型协作层。
- 把开发、研究、视觉和文档交给各领域 Skill。
- 继承用户原始授权：评审只读，修复/实现可在会审后继续，发布/删除仍需相应审批。
- 保留网站案例作为最小示例和真实 gotcha，不保留网站专属流程。
- 以节省 Codex token 为首要目标，增加 Token ROI Gate、非重复分工和紧凑决策包。

## 回退点

旧 `website-visual-co-review@1.0.0` 完整目录与 `.skill` 包归档在本轮 outputs 中，可恢复但
不应继续安装，否则会与通用协议产生路由噪声。

## 证据

结构校验、路由人工走查和打包完整性将在安装前记录；独立新会话行为回放仍标记 not-run。
